# EIN — Exposição e Intervenção na Norma

Portal estático para GitHub Pages com quatro níveis de intervenção:

1. Marcar a norma
2. Correção à vista
3. Escrever brasileiro
4. Cucagrafia

## Estrutura

- `index.html` — portal EIN
- `marcar-a-norma/index.html`
- `correcao-a-vista/index.html`
- `escrever-brasileiro/index.html`
- `cucagrafia/index.html`
- `assets/flags/` — bandeiras gráficas usadas pelos conversores

Todos os caminhos são relativos e funcionam em GitHub Pages.
